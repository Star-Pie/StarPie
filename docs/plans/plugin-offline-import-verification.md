## 范围与现状

原手动入口只接受社区 DLL，官方 `.spkg` 会被 DLL 扫描器拒绝。首次引导失败后主要提供换通道重试，缺少断网替代路径。本次统一文件导入，直接识别官方原始包，保留社区 DLL 路径；首次引导可转到插件页导入，新项默认禁用，更新保留启用/预加载偏好。联网时可将单个原始 `.spkg` 保存到用户选定位置，复制到其他电脑后直接导入，无需解压。

仅修改官方插件客户端、插件页/首次引导与相关四语词条、嵌入目录声明及专项护栏。不改 SDK、动作执行、配置格式、版本或发行流程，不提交/推送/合并。`H:\design` 的 README、支持者素材和 WPF 临时工程保留原状。
