# 最多五级子菜单：实施准备

## 基线与边界

用户正在验收小键盘1827，宿主DLL为 `ED82B05C213104FF91312FD52F5BBBF551531626CB799117CB2DD08A8693210E`。本文件只记录后续实现准备，不改变该候选或声称五级已实现。沿用宿主隔离工作树 `codex/restart-update-reliability`；实施前再次核对1827来源、未提交变更及14个既有诊断文件哈希。新产品候选必须使用新的时间输出，不能覆盖1827。

最多五级指一条动作子菜单分支的深度，含一级主轮盘；不是滚轮／Tab切换的命名WheelLayer数量。导航、几何与配置属于宿主；实际动作继续交现有动作队列和PluginHost，不能做成复刻输入钩子的插件。

## 已核对的源码事实

- `ActionItem.SubActions` 已递归建模，Clone递归复制，不必引入另一种动作树或重命名配置。
- `WheelLayer` 表示命名轮盘，现有 `ActivationTrigger`、中心动作和方案克隆须保留。
- `GestureController.EndActiveGesture`、`TryResolveReleasedAction` 和高亮投递只持一级／二级索引；目前不能仅放宽设置数字就支持五级。
- `RadialWindow.RenderSubTier(parentIndex)`、缓存与 `HighlightSector` 也只有二级；Fan有固定3槽几何，Wheel支持不同子数，两种样式均需明确覆盖。
- `WheelProfile.GetEffectiveAction` 处理本地禁用、全局同层继承、回退Global第1层与扇区方向映射；继承结果会Clone，克隆对象引用不能当稳定节点身份。本地已配主项的空子项不会继承无关Global子项。
- SDK旧 `InteractionTarget` 只含Sector／SubSector，不能重解释这些字段为深层索引。

## 配置与交互规则

每个命名WheelLayer增加 `MaxMenuDepth`，缺失默认2、最高5；现有EnableMultiTier关闭时仍只一级。新增紧凑深度选择跟随当前方案和当前命名层。复制／导入／导出／撤销均保留字段，初始化和浏览不保存。降低深度只隐藏更深内容，不能删除SubActions。无效值在运行时限制范围，避免普通浏览破坏未知数据。

主轮盘方向与前两级现有布局不变。额外层只沿当前活动分支展开，不把整棵树一次绘出；“同时展开全部子环”维持原有二级展示，不能扩展成五级全树展开。普通按住松键与定格点击共享同一导航模型；不把定格关闭、外部点击吞键或音量即时动作重写一套。

空间足够则沿原点向外逐级展开。空间不足时在既有外层区域显示下一级，并显示当前路径和返回入口，不搬动定格原点、不为了塞进屏幕改扇区方向。返回导航与中心动作分开；Esc继续取消整个会话。返回入口须纳入真实几何命中与定格内外判定，不能被当轮盘外点击。

进入子菜单后，返回、间隙、空槽及父路径失效不得回退执行父动作。保留旧二级中尚未进入子菜单时的父动作规则；分支节点、深度上限及父项自身动作的行为必须以旧候选反例绑定，不能以“有SubActions就一律删除父动作含义”代替兼容。

## 实施结构与允许路径

1. 新建有界路径／导航状态，最多5个索引。会话绑定来源profile／layer、路径、来源修订及有效动作快照；继承克隆只用于展示与执行快照，不作来源ID。层重排按对象身份保持，删除、来源变更和新手势使旧路径与延迟回调失效。
2. 新增按路径解析入口，保留旧 `GetEffectiveAction(sector,subSector,...)` 及其行为。路径解析复用原有继承规则，只在同一有效分支向下走；显式None、空槽、目标插件不可用仍不可执行。
3. 在UI准备阶段创建冻结几何快照，输入钩子只读活动分支和版本，最多5步命中，不扫描目录、不等待、不递归构造WPF。缓存键含来源修订、完整路径、样式、DPI和显示方式。
4. 控制器把二元选择整合为路径状态，保留旧二级适配入口用于既有测试；普通松键／定格点击只把当前有效目标交给一次执行队列。返回和过期回调不提交动作。
5. 以小型partial／辅助类整合现有RadialWindow及设置画布，避免重写大型XAML。编辑界面使用面包屑进入／返回，既有动作参数表单和插件分组下拉复用。

允许：WheelLayer／WheelProfile／ConfigManager、GestureController、RadialWindow相关partial、独立路径／几何辅助类、SlotViewModel／必要设置页、四语言文案、相关docs和scratch测试。SDK若需要完整路径，必须新增只读路径／构造器重载并保留旧Target与原构造器，经公共契约独立审查后再定版本，不能直接改变旧记录结构。禁止修改已冻结的小键盘插件／输入会话、自动更新、自启动、旧发行包、其他工作树和用户配置；不执行真实动作或输入。
