# 临时小键盘：实施范围

## 基线与交付顺序

宿主沿用 `codex/restart-update-reliability` 隔离工作树，基准为 main `773e8c8` 加已经验收的 1641 beta.4 改动。1641 的 DLL、源码快照与验收记录保留在更新重启证据目录，不覆盖该候选。官方插件使用独立工作树 `H:\starpie-official-worktrees\temporary-keyboard`、分支 `codex/temporary-keyboard`，基准 `c1afceeded7697dba8dc1c5eef64f9138a7fe5ac`。宿主版本仍为 beta.4，不修改 beta.3 发行资产。

先单独交付临时小键盘，再做菜单最多五级展开；这里的菜单深度不等于滚轮／Tab 切换的命名 WheelLayer。不得将五级菜单混入本候选。

## 产品行为

- 数字、字母、功能、全键盘和自定义五种布局，由轮盘动作选择初始模式，面板内可切换。
- 连续点击输入，窗口不激活、不抢走原应用的输入焦点。Esc、关闭按钮、目标应用改变或失效、暂停、插件停用均关闭会话。
- Shift／Ctrl／Alt／Win 是面板内的一次修饰选择，不在两次点击之间保持系统按键按下；主键点击时作为同一次输入发送并成对释放。
- 自定义页固定 3×4 个槽位，支持命名方案。轮盘动作可指定初始方案，面板可切换方案。
- 每槽可绑定另一个已安装且启用的插件动作及参数；不可用项灰显，保存原引用，不自动安装或启用目标插件。
- 编辑方案与动作绑定在显式打开的设置窗口中完成。输入面板关闭后再进入编辑，编辑结束需要用户重新在目标应用呼出面板，不暂时放宽目标焦点校验。
- 文字输入和按键输入区分：Unicode 文字不宣称支持 IME 组合；全键盘中的按键通过系统布局处理，IME、UIPI 和专业软件兼容由实机验收。

## 分层与兼容

界面、布局、修饰选择、方案及私有配置属于独立官方插件 `starpie.plugin.temporarykeyboard`，只引用 SDK/BCL/WPF 框架，无 NuGet 或主程序集引用。不安装插件时不建键盘窗口、不注册面板会话；关闭后释放窗口和订阅。

宿主负责原目标绑定、取消、能力门禁、动作选择与参数表单、队列和运行时租约。不能从 WPF 点击直接调用旧同步 SendText／SendHotkey，也不由插件复制 SendInput。SDK 1.15 只增可选派生上下文与强类型输入会话、插件动作绑定；旧接口、程序集身份和已有插件行为不变。跨插件请求新增明确能力声明，不借用与其后果不同的旧能力。

会话按宿主插件实例代际绑定。文字、快捷键和自定义动作使用同一目标会话与既有顺序动作队列；入队复制数据，执行前复用 HWND／PID／前台及会话代际校验。关闭、暂停或停用使未执行请求失效；快速点击有有界待处理数，满时明确返回忙碌，不无限堆积。初始动作返回后可继续点击，不长期持有阻止停用的调用租约。

Esc 的按下／抬起由既有宿主钩子快速配对处理，只切换会话状态并投递取消；不进行 IO、等待、建窗或目录扫描。目标变化沿用事件驱动监控，不增加轮询。编辑绑定打开现有宿主参数表单，且不自动调用真实动作。

## 修改范围与委派

宿主允许修改 SDK 新增接口与版本点、PluginContext／面板服务／运行时撤销接缝、既有钩子的轻量取消入口、参数编辑器、四语言文案、相关文档与隔离测试。设置主页面、大型轮盘渲染、菜单深度、自动更新发行包不在本阶段范围。

官方插件只修改新增 `src/StarPie.Plugin.TemporaryKeyboard`、对应测试与必要模块登记／SDK 同步。既有插件、其他工作树和用户配置禁止修改。

DeepSeek/MAX 优先承担纯布局、一次修饰状态、命名方案数据和无副作用测试；主代理负责公共契约、输入目标与生命周期、WPF 整合和最终验收。Kimi/MAX 给定材料评议供参考，其中“编辑期间放宽失焦关闭”的建议未采纳。实施完成后交由独立原生工作者审查；同时最多两位工作者，不递归委派。

## 验证与完成条件

- 确定性：五种布局、常用数字／标点／功能键、修饰选择一次消费、12 槽命名方案往返、损坏数据和不可用绑定保留。
- 宿主：缺能力拒绝、旧上下文兼容、队列快照／有界顺序、目标变化／关闭／暂停／代际更换取消、禁用目标不加载、参数校验、空参数无副作用和租约释放。
- 构建：新时间戳 Release 宿主输出；插件独立输出，不能包含宿主 DLL 或 SDK 私有副本。候选哈希绑定回归与安全自检。
- 自动测试禁止真实输入、插件动作、窗口操控或安装。窗口构造／模板验证不扩大为真实交互验收。
- 人工：真实文字／快捷键、连续点击、Esc、切换应用、管理员目标、IME、多屏 DPI、自定义动作和插件停用释放。未通过不得合并或发布。

不因自设调用次数或修复轮次停止；出现无进展按具体故障更换方法，保留实际证据。没有本阶段 commit、push、Tag、打包或发布授权。
