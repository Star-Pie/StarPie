# StarPie 主题工作室

在设置控制台打开「外观样式」，顶部的「主题工作室」提供五种整体美术风格：

| 风格 | 视觉特点 |
| --- | --- |
| 纸感极简 Paper | 暖纸底色、细线、小圆角与红棕强调色 |
| 曜石科技 Obsidian | 深色底、青绿高亮与轨道装饰 |
| 森林柔和 Grove | 鼠尾草配色、柔圆卡片与哑光轮盘 |
| 冰川玻璃 Glacier | 冰蓝配色、半透明轮盘与细刻度 |
| 复古像素 Pixel | 方角卡片、粗线、硬阴影与像素刻度 |

点击卡片查看示例，再点击「应用风格」。设置窗口、已打开的宿主弹窗与轮盘会即时更新；应用后会保存选择，下次启动继续使用。

控制台和宿主弹窗的标题栏、品牌标志与提示框也跟随当前主题。窗口按钮沿用最小化、最大化／还原、关闭的含义；关闭控制台仍是隐藏，退出后台程序使用托盘菜单。确认框保留默认按钮与取消操作，只有「是／否」的确认需要明确选择。

普通宿主窗口采用约 8 DIP 的圆角，最大化时恢复直角边界。界面文字默认通过 WPF 系统资源跟随 Windows 消息字体；在「系统设置 → 界面字体」中也可选择「跟随主题字体」或已安装字体。这个选择不修改原轮盘和每扇区字体。Windows 字体同步与 MacType 注入是不同机制，本功能不保证第三方渲染注入生效。

## 自定义

1. 选中内置风格，点击「复制并编辑」；也可以「新建」。内置风格始终保留。
2. 输入主题名称。十二项配色支持 `#RRGGBB` 或 `#AARRGGBB`，也可点击色点打开选色器。
3. 展开「进阶」调整字体、深色基底、圆角、描边、阴影、轮盘透明度与装饰。字体使用已安装的字体名称，可用逗号指定回退字体。
4. 编辑器与右侧轮盘即时显示草稿；当前设置仍保持原样。无效字段会禁用保存，对比度不足会提示。
5. 点击「保存并应用」创建或更新自定义主题。「取消」放弃草稿，「撤销本次修改」恢复进入编辑时的值。

自定义主题可重命名、删除或导出。删除当前主题后回退到纸感极简。单次支持保存最多 128 个自定义主题。删除后若需恢复，请重新导入事先导出的主题文件。

## 轮盘与旧设置

「轮盘跟随整体风格」控制整体主题是否用于轮盘。关闭后，轮盘继续使用原来的主题与配色设置。独立二级轮盘的配色始终优先，每扇区的自定义文字颜色与字体也会保留。

风格调整材质、字体与装饰，不改变轮盘尺寸、扇区角度、命中区域、动作映射和手势操作。现有几何形态仍由原设置控制。第三方插件自行绘制的界面由插件管理。

旧配置没有整体主题选择时，继续使用原有外观。在侧边栏选择「系统／浅色／曜黑／钛灰」会退出整体主题。原轮盘配色与自定义配色预设不会被删除。

完整配置导入／导出包含主题选择、自定义主题和轮盘跟随开关。选中主题缺失或无效时，以纸感极简安全回退，并显示提示。

## 主题文件

「导出」生成 `.starpie-theme.json` 文件；「导入」也支持 `.json`。每次导入都会创建新的主题标识，不覆盖已有主题；导入后选中卡片并点击应用。文件只包含主题外观，不携带动作或个人配置。

[themes/](../themes/) 提供五份可以直接导入的完整示例。格式版本为 `1`：

```json
{
  "schemaVersion": 1,
  "theme": {
    "id": "paper",
    "name": "Paper",
    "isDark": false,
    "colors": {
      "background": "#F5F1E8",
      "surface": "#FFFCF5",
      "sidebar": "#EDE7DA",
      "text": "#252820",
      "muted": "#626458",
      "accent": "#B54735",
      "border": "#D2CCBE",
      "wheelBackground": "#FFFCF5",
      "wheelBorder": "#858373",
      "wheelHighlight": "#B54735",
      "wheelText": "#252820",
      "wheelHighlightText": "#FFFFFF"
    },
    "fontFamily": "Microsoft YaHei UI, Segoe UI",
    "cornerRadius": 4,
    "strokeWidth": 1,
    "shadowBlur": 8,
    "shadowDepth": 2,
    "shadowOpacity": 0.1,
    "wheelOpacity": 0.96,
    "decoration": "Paper",
    "decorationStrength": 0.5
  }
}
```

文件大小上限为 64 KiB（UTF-8），格式和字段会在写入配置前校验。省略可选字段时使用默认值；不接受未知格式版本、无效颜色、空对象、外部字体路径或越界／非有限数值。装饰类型支持 `Paper`、`Orbit`、`Soft`、`Glass`、`Pixel`。

| 参数 | 范围 |
| --- | --- |
| 圆角 | 0–24 |
| 描边 | 0.5–3 |
| 阴影柔和度／位移 | 0–30／0–6 |
| 阴影强度 | 0–0.5 |
| 轮盘不透明度 | 0.6–1 |
| 装饰强度 | 0–1；0 关闭装饰 |

## 开发验证

在安装 .NET 8 SDK 的 Windows 环境运行：

```powershell
dotnet run --project scratch/test_art_styles.csproj -c Release -- --test-instance
dotnet run --project scratch/test_art_styles.csproj -c Release -- --test-instance --render
```

验证必须带 `--test-instance`，否则拒绝启动。验证不显示窗口、不执行用户动作，使用独立临时配置目录并禁用自启动同步。`--render` 将原生 WPF 画面保存到 `artifacts/art-styles/`，用于检查五种风格、编辑器和设置页面。完整交互回归依照 `AGENTS.md` 由用户手动执行。
