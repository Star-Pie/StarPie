# UI、轮盘与 DPI 规范

## 配置识别与迁移（在研）

- 手势动作页保留配置下拉，增加图标和简称切换条，用选中标记、背景和边框区分当前编辑对象；长名称省略且提示全文。图标按需加载与缓存，不在钩子里枚举程序。
- 绑定条目支持软件库更换和移除，保留窗口捕捉/软件库/浏览添加。关闭程序情景须先取得独立有效键，取消录制保留原模式和草稿。
- 配置名、层名、运行切层徽标和外观预览一致，保留原徽标开关、主题、时长与滚轮/Tab 切层语义。
- 导出可选含 SVG 的便携包或原 JSON。资源后台校验，界面线程提交；窗口关闭或准备期间配置变化时取消导入并回滚资源。取消命名不得导入。

## 极坐标与命中

WPF 坐标系中：

```text
theta = atan2(deltaY, deltaX)
```

角度 0 指向正东，Y 轴向下。4/8/12 扇区按 `2π/N` 等分，既有索引与空间方向不能改变。

蜂窝二级菜单禁止按欧氏圆心距离选叶片，必须比较归一化后的角距离：

```text
target = argmin(abs(NormalizeAngle(mouseAngle - leafAngle)))
```

这样左右移动总是命中同侧叶片，不随半径和视觉偏移反转。

## 渲染与 DPI

- `RadialWindow` 和 `Renderers/` 是轮盘绘制入口；几何计算与视觉样式分离。
- 透明窗口、混合 DPI 和多显示器位置计算必须明确物理像素与 WPF DIP 的边界，不在同一表达式里混用。
- 高频画刷、笔刷、几何在不可变后 `Freeze()`；避免每帧分配集合、字符串或新资源。
- 高亮与光晕使用已有动画节奏，不能通过高频声音、同步 IO 或 Dispatcher 堆积来驱动。
- 第 0 扇区方向、扇区编号和用户既有配置是兼容契约。

## 设置控制台

- 复用现有 `DynamicResource`、控件样式、间距和字体层级。
- 简单/高级模式的差异是信息密度，不应改变配置语义。
- 实时画布需要能反映当前编辑对象；UI 初始化时使用 `_isUpdatingUi` 等守卫，防止控件回写配置。
- 新增 DataTemplate 文案优先绑定视图模型的本地化属性。`Name` 不能跨 DataTemplate 命名域充当可靠 i18n 护栏。
- 插件动作 UI 固定为一个顶层“插件动作”选项和一个按插件分组的子下拉；分组头不可选择。

### 关于页内置更新日志

- 根目录 `CHANGELOG.md` 是版本日志的唯一内容来源，由主程序工程嵌入为 `WinPieGestures.Changelog.md`；不再手写 XAML 版本卡片或维护对应的历史翻译词条。修改日志后，下次构建自动带入，不修改运行时版本号或 SDK。
- 只在首次进入关于页时读取与解析资源，保留文档版本顺序并省略空的 `Unreleased`；最新非空段落默认展开，历史段落正文按展开创建、折叠释放。正文以只读可复制的 Markdown 原文展示，不自动翻译，不执行 HTML 或加载外链图片；标题、说明与错误提示覆盖四语。
- 展示不依赖联网、安装目录或额外 Markdown/浏览器组件；资源缺失、空内容或无法读取时显示明确的本地提示，不回退到过期静态卡片。原始文本读取与导出均有大小上限。
- “查看完整 CHANGELOG”使用相同的内置文档，仅在用户点击时导出到随机命名、禁止覆盖的临时 `.md` 文件并调用默认应用；不向安装目录写入文件，也不优先使用可能遗留的外置日志。运行期间不会自动获得未来版本的日志。
- 离线验证：`dotnet run --project scratch/changelog-tests/ChangelogTests.csproj -c Release -- --candidate <本轮 StarPie.dll 的绝对路径>`，覆盖精确嵌入、无外置文件读取、解析边界、空/缺失内容、临时导出、正文懒加载与实际资源布局；不联网、不启动外部查看器或产品窗口。真实显示、复制及默认应用打开仍需人工验收。

### 关于页更新源

- 软件更新卡片直接放在“关于软件”顶部版本信息卡下方，不再放在系统设置页。关于页的检查按钮原地检查，不切换页面；更新偏好默认展开，首次检查之前即可选择来源、通道和下载加速，仍可手动折叠。
- `UpdateReleaseSource` 独立保存主程序发行版来源：`github`（默认，兼容旧配置）或 `atomgit`（`Star-Pie/StarPie` 国内镜像）。`UpdateProxySource` / `CustomProxyUrl` 的含义和插件下载行为不变；选择 AtomGit 时仅禁用关于页的 GitHub 加速下拉，保留原选择。
- 检查、包下载、历史回退和发行版网页跟随所选来源。切换来源只保存配置并清除旧候选、已下载待安装引用和上次检查时间，不立即联网；取消旧请求并使用修订号丢弃旧检查结果及进度回调，切回原来源也不复活旧结果。
- AtomGit 只访问公开 Release API，无客户端 Token，不回退 GitHub；缺少对应 ZIP 或 `SHA256SUMS.txt` 的未完整镜像版本不作为候选。附件仅使用 API 实际返回的 HTTPS 地址，不推测文件地址。镜像可落后，界面只能表述“所选源暂无更新”，不能据此断言官方最新版。
- AtomGit 下载必须读取对应文件的 SHA-256 并校验完整包；失败不进入安装就绪态。重定向仅允许 AtomGit/GitCode/OBS 的 HTTPS 主机，不跟随至 GitHub。每次下载使用独立临时路径，避免取消旧下载时删除新任务的文件。
- 选择 AtomGit 后的更新检查不额外启动 GitHub 贡献者名单同步。原有更新覆盖与重启过程不在本功能内重写。
- 离线护栏：`dotnet run --project scratch/update-source-tests/UpdateSourceTests.csproj -c Release -- --candidate <本轮候选 StarPie.dll 的绝对路径>`。仅使用模拟 HTTP、临时文件、配置往返和无 Window 的控件资源探针；不下载真实包，不执行更新、回退或重启。源切换、语言/主题/DPI 和真实镜像接口仍需人工验收。

### 二级菜单父扇区锁定

- 触发设置中的“进入二级菜单后锁定父级扇区”默认关闭，适用于按住鼠标或键盘触发键的普通轮盘；桌宠粘滞轮盘不在此开关范围内。
- 开启后，实际进入有效二级子项才锁定父扇区；“同时展开全部子环”仅控制显示。跨越一级角度边界保持父项，退回一级区域并越过防抖阈值后解锁。
- 移出可选子项、进入禁用或占位子项后松手不执行父动作。切层、结束、取消、暂停和新手势会清理会话状态。
- 实时预览沿用渲染尺度和同样的锁定规则。蜂窝扇几何在界面准备阶段冻结，输入热路径只读取快照，以角距离选择可见候选。

## 主题和可访问性

- `ObsidianDark`、`TitaniumGray` 下正文与控件文字对背景对比度至少 4.5:1。
- 标题和主要文本使用项目高亮前景资源，不写与主题绑定的固定灰色。
- 所有弹窗在 `<Window.Resources>` 内具备自包含样式，并在构造时调用：

```csharp
AppThemeManager.ApplyTheme(
    this,
    ConfigManager.CurrentConfig?.AppTheme ?? "System");
```

- 用户可见文案覆盖 `zh-CN`、`zh-TW`、`en-US`、`ja-JP`。新增 XAML/代码路径不得硬编码单一语言。

## 快捷键录制

`HotkeyRecorderBox` 必须禁用 WPF 默认焦点导航，确保 Tab 及系统组合键能够被录制：

```csharp
KeyboardNavigation.SetTabNavigation(this, KeyboardNavigationMode.None);
KeyboardNavigation.SetDirectionalNavigation(this, KeyboardNavigationMode.None);
KeyboardNavigation.SetControlTabNavigation(this, KeyboardNavigationMode.None);
```

在 `OnPreviewKeyDown` 中处理 `Key.Tab`、`Key.System` 和修饰键，不让焦点切走。

## UI 改动验证

1. Release 构建和相关静态护栏。
2. 以至少浅色/深色、简中/英文检查新增区域；涉及本地化时扩展到四语系。
3. 小窗、常用 DPI、多显示器或缩放相关场景。
4. 动态列表的空、单项、多项、长文本和失效引用状态。
5. 最终由用户进行视觉、手感与真实交互验收；AI 不自动运行会弹窗的 UI 套件。

### 应用识别入口与应用生效范围

- 手势动作页在方案区上方提供唯一全局应用识别区，独立于 Global/专属方案及画布/列表视图；仅高级模式显示，简单模式折叠入口但保留组件识别配置及其生效状态。
- 高级模式采用随内容宽度的紧凑条，窄窗可换行；长说明放入本地化提示并提供开关的辅助说明，不占常驻第二行。
- 触发页的当前识别方式和跳转入口同样仅高级模式显示，不提供第二个写入开关。开关变更、配置加载和语言切换时同步两处状态。
- 修改识别方式仅导航到手势动作页并定位/聚焦开关，不切换方案或编辑视图、不改配置。

### 同应用多触发轮盘

- 手势动作页的当前配置当前层独立触发键摘要与录制入口直接展示在情景摘要卡片右侧，简单和高级模式均可使用；状态徽标明确区分“未设置独立键”“录制中”“已绑定：…”与“冲突，未启用”，录制完成后立即刷新为已绑定状态并把按钮切换为“重新录制”，取消、冲突或失败均保留原绑定。高级列表视图继续保留共享触发条，画布视图不再重复显示第二套录制按钮。
- 配置快捷列表在第一行当前配置方案下拉框右侧提供三态显示切换（仅文字、仅图标、图标和文字），切换与刷新保持下拉选中和横向滚动位置；快捷栏隐藏底部无效滚动条，鼠标悬停在该区域时滚轮上下滑动直接驱动图标列表左右滚动。纯图标模式提供统一尺寸、完整名称提示与可访问选中标记；纯文字模式不触发图标加载且丢弃过期异步回调。
- 情景配置区采用紧凑摘要卡片：默认仅显示绑定摘要芯片、`+ 添加程序` 与按需展开的 `管理…` 详情；切换配置时详情自动收起；平行模式折叠程序绑定区；Global 使用简短提示并把完整说明移入悬停提示；使用自适应 WrapPanel 避免窄窗、长文本、英文及高 DPI 裁切。
- 录制目标固定到当前方案与当前层；切换方案/层、关闭窗口、回到简单模式或取消均结束录制，旧排队输入不能写入新目标。交互控件的左键按下先取消录制；取消按钮不会因后续 Click 再次开始。在空白区域可录制左键。
- 键盘录制只消费按下事件，不将录制前已按住键的松开误认成新触发。Esc 取消；四语状态与冲突反馈使用 I18n。隐藏高级入口不重置已存触发。

### 设置字体列表的按需加载

- 轮盘与中心文字的字体选择先只建立常用预设及当前字体；各下拉首次展开时独立枚举安装字体。展开后普通外观/扇区刷新复用列表，语言变化则更新预设并重新按需加载，不提前枚举隐藏下拉。界面字体保留原有按需路径。
- 重建及恢复选中值时使用初始化守卫，不能触发字体SelectionChanged保存配置。两处字体按完整Tag精确匹配，单字体不被同前缀的回退链替换；未安装或组合字体保留合成选中项。
- 无窗口组件探针用于控件条目、分配与选择保护，不能据此断言完整设置窗口内存或泄漏已解决。字体首次展开、语言、主题和DPI的实际显示仍需人工验收；30秒隐藏复用与回收策略不在此改动中调整。


## 中心图片缩略图解码

设置页的32 DIP中心图片缩略图显式复用 IconHelper.GetCustomImageSource 的128像素解码上限和冻结缓存，为高DPI与设置缩放保留余量；不要先直接用BitmapImage完整解码原图。切换到非图片模式时清空缩略图引用，保留用户原始图片路径和中心图标显隐配置。空值/无效图片沿用既有清空或回退语义，路径输入与文件选择复用同一预览刷新入口。

轮盘中心背景图复用同一有界加载器，解码长边上限1024像素并冻结ImageBrush；保留拉伸、透明度及已有亮度采样，不能将原尺寸图片常驻。该上限和缩略图上限是不同缓存项；不改变其他自定义图标的默认256像素策略。真实背景显示、DPI及缩放仍需人工验收。

## 触发后定格与批量图标导入（beta.3）

- 触发页的全局定格开关在简单和高级模式均可见，默认关闭。开启后保留触发起点；释放按键和悬停不执行动作，也不按等待时间关闭。点击有效叶子或中心动作后先结束会话，再走原有目标校验及动作队列；父菜单继续展开，空槽保持显示。
- Esc、再次触发、外部点击、前台目标变化、暂停或配置变化会取消；已吞掉的鼠标按下须连同抬起消费。左键自身作为触发时，有效扇区内左击优先确认；Esc或外部点击取消。定格期间不启动音量距离调节等即时动作。
- 确认命中使用轮盘实际渲染路径和中心椭圆，不将扇区间隙或透明角落作为动作。混合DPI、屏幕边缘及真实输入成对消费仍需实机验收。
- 定格悬停与点击共用实际图形命中：远离轮盘、扇区间隙及透明区域清除选择和高亮，发布无目标以取消悬停音效；中心取消区保留已展开子菜单状态并以 `Core` 取消悬停音效，空区与中心取消区回到原已展开二级时不重播 `SubmenuExpanded` 或父扇区反馈；从二级退回同一已展开一级扇区时保留一级目标 `SelectionChanged` 恢复一级悬停反馈；直接切入另一已展开父菜单时正常发布新的 `SubmenuExpanded`。输入线程只合并最新坐标，界面线程在呈现回调按静止 `1.0x` 几何完成初始命中，并在入场缩放动画结束后刷新静止光标命中；旧代际、旧坐标和异步外部点击不得覆盖或取消新会话。普通手势仍保留按方向选择的原行为。
- beta.4候选：定格也遵循启用的边缘防溢出策略，以修正后的实际物理中心进行显示、扩展阈值和命中；关闭防溢出时保留触发起点。定格不为适配边缘而移动用户光标。选择二级扇区时清除父扇区视觉高亮，保留父级导航状态；返回一级时再恢复该层选中反馈。五级展开尚未实现，不能从本项修复推断已支持五级。
- 定格点击以实际命中的动作确认：一级扇区有自身有效动作时，即使带子菜单也执行该动作；没有自身动作的父项才只展开并保留轮盘。悬停展开和二级动作点击保持原语义，自动展开子轮不应让一级动作失去点击入口。
- 图标选择器可多选SVG，或仅导入所选文件夹本层SVG；不递归、不解压。沿用单色path能力，拒绝变换、描边、多色、外部引用、透明/不支持的颜色和图形，不静默丢弃可见内容。单文件上限2 MiB，禁用DTD及外部解析；使用唯一文件名，不覆盖已有图标。
- 批量操作逐项处理，单项失败继续；完成后只刷新一次并保留原选择，在同一区域汇总成功、跳过、失败及原因。关闭选择器取消导入并回滚本批已创建的文件。
- “保存更改”成功使用现有保存状态反馈，不再弹成功对话框；失败保留错误反馈，不显示成功。

## 设置界面预览清晰度、尺寸下限扩展与删除一致性

- 尺寸滑块上下限统一由 `SyncDimensionSliderBounds` / `SetSliderValueWithBounds` 在写入 `.Value` 前更新：加载配置与重置尺寸时按目标值恢复默认区间并在超限时向上扩展 `Maximum`，交互拖动时只按需要放宽外环上限而不收缩已有较大值，确保重置后再导入较大尺寸的配置或执行导入导出往返时主轮与子轮尺寸不再被控件范围截断。
- `LiveWheelPreviewCanvas`、`MappingsWheelPreviewCanvas` 及其缩放视口容器和动态创建的预览 `TextBlock`/`Image` 显式覆盖全局 `Display` 文本样式为 `TextFormattingMode.Ideal`、`ClearType` 与 `BitmapScalingMode.HighQuality`；设置页界面缩放在 `Scale != 1.0` 时切换缩放根容器与文本框样式为 `Ideal`，`100%` 时保持原 `Display` 文本样式。
- `RenderMappingsWheelPreview` 外圈子菜单在 `MappingsCanvasShowText` 开启、整体或子项处于 `TextOnly` 布局或无有效图标可绘时渲染与主扇区一致的居中省略 `Ideal` 标签，并支持 `custom:` 自定义子图标解析与 Wheel/Fan 选中高亮及点击命中语义。
- 删除已保存配置方案与删除层在修改或确认前停止 400ms 自动保存防抖计时器；删除配置方案改为全部四语 `I18n` 文案并在后端校验删除成功后再重载界面；删除层采用同步落盘并立即发布路由更新。切换应用浅/深色主题改为走防抖自动保存并由主题变更通知按可见页签条件重绘预览，避免隐藏页签与同步写盘阻塞点击。

## 多级子菜单

在「手势动作」页选中方案与轮盘层，设置「菜单级数」（2–5）。在右侧实时交互画布点主扇区，再点外圈子项。单击选中扇区，在同页左侧修改动作，通过编辑下一级入口继续展开。画布随修改刷新，可用路径返回祖先，或用撤销、重做恢复编辑。中心圆独立于子菜单。

普通轮盘在划入分支时展开，下一级叶子由松开触发键确认。定格模式点分支进入，再点叶子确认。空间不足时深层分支复用外圈区域。「返回」回到上一层，Esc 取消整次轮盘。原树形布局的「同时展开」作用于第二级。

## 固定整圈菜单（v2.0.1-beta.5）

在「手势动作」选择方案和轮盘层。一级配置方向，二级在对应父项下添加、排序或编辑子动作，保留外圈子环与蜂窝扇两种原有布局。第三级起可启用固定整圈。第 3–5 级默认分别为 12、16、20 个槽位，可从 4 起逐个增加，上限分别为 23、30、37。各圈的第一个槽位朝右，按顺时针编号。同一层的所有父项共用这一圈的位置。

单击扇区只选中它。左侧可以指定名称、动作和上级，再应用到所选槽位。调小等分数时，高编号槽位暂时隐藏，增大后恢复。修改槽位数后，外圈子环按新角度均分，蜂窝扇从整圈六边形格中均匀取位。两种样式共用槽位编号和动作归属，切换样式也会保留配置。

在多层画布上，可将三级至五级的已配置槽拖到同一级的空位，或与另一已配置槽互换。子项随原父槽移动，包括暂时隐藏的子项。按住 Ctrl 投放只复制当前槽；被覆盖槽原有的子项保留为独立槽。一次撤销可恢复整次操作，Esc 或拖出有效区域可取消。

开启触发设置中的「唤出时直接同时展开一二级轮盘」并将当前层设为「全部常驻」后，可以直接选择外圈的独立槽。蜂窝扇同时显示各父项原有的二级扇瓣和三级至五级蜂窝格。蜂窝扇默认逐级唤醒，只有两项均开启才整盘显示。外圈子环开启同时展开但层设为逐级时，一级和原二级子环同时出现，三级至五级沿当前父项展开。配置画布保留空位供编辑。逐级模式统一使用触发设置的展开距离。沿有子项的父扇区向外划到阈值，即显示该父项的下一级。返回内圈可退回，取消和空槽不会触发其他动作。
