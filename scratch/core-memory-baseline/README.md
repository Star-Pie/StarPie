# 最低插件内存基线

仅用户手动启动两个隔离场景：纯宿主、宿主加启动程序/文件夹/网址。两组使用同一候选与程序生成的完整首装配置，关闭更新检查和首次联网安装引导；插件系统保持启用。核心组只复制已经安装并启用的三个包，其余插件及私有设置不复制。没有写入日常配置或安装位置。

AI只运行配置生成、复制校验、预检和只读采样；不运行启动入口。`Start-Case.ps1 -ValidateOnly` 不启动程序。真实启动使用生成的 `Start-host-only.cmd` 和 `Start-core-three.cmd`，必须先从托盘正常退出上一实例。每个场景只能启动一次，拒绝覆盖已有运行和已改动夹具。

先保持仅托盘采样，再手动打开设置（不展开字体、不执行动作），最后正常关闭并等待至少45秒。按实际进程年龄记录，不能将不同配置形状或一次GC时序差解释为插件因果成本。测试实例禁止同步启动项，但仍有真实输入钩子，因此仅用户操作启动和退出。

本目录不是主程序发行包；不会将官方插件放入主程序输出。核心包只在隔离的LocalAppData中作为明确测试夹具。全部路径、候选与复制文件哈希记录在session.json。
